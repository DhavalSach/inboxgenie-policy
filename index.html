About Inbox Genie

Inbox Genie is a mobile application that helps users connect and manage their Gmail mailboxes in one place. Users choose whether to connect a Gmail account and can unlink a connected mailbox at any time.

How Gmail access works

Inbox Genie requests Gmail permissions only after a user chooses to connect a mailbox. Gmail access is used only to provide features the user has authorized, such as viewing and managing connected mailbox information and performing user-requested actions.

Users can unlink a connected mailbox through Inbox Genie. Unlinking revokes Google access and removes associated indexed mailbox data.
